# Curri

> Curri is a last-mile and same-day delivery platform for construction and
> industrial supplies. Its GraphQL API lets you request quotes, book on-demand
> and scheduled deliveries (Hotshots, Dedicated fleets, LTL), and track drivers
> in real time — connecting your systems to Curri without logging into the app.

- Generated by the API Evangelist enrichment pipeline from apis.yml + repo artifacts.
- API style: GraphQL. Endpoint: https://api.curri.com/graphql
- Auth: HTTP Basic (base64 of userId:apiKey); separate Sandbox key for test mode.
